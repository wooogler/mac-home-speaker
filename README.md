# mac-home-speaker

안 쓰는 맥북을 한국어로 말하는 홈 스마트 스피커로 바꿔 줍니다.

"스피커야, 아이유 밤편지 틀어줘", "내일 7시에 깨워주고 날씨도 알려줘", "오늘 일정 뭐 있어?" 같은 말을 알아듣고 목소리로 답합니다. 호출어 감지, 음성 인식, 음성 합성은 모두 맥 안에서 돌고, 무엇을 할지 생각하는 두뇌만 클라우드 AI API(Claude, ChatGPT, Gemini 중 하나)를 씁니다.

```
마이크 → 호출어(openWakeWord, 한국어 호출 문구) → 음성 인식(Whisper, 로컬)
      → 두뇌: Claude / ChatGPT / Gemini (음악·알람·일정·메일·웹 검색 도구) → 음성 합성(Qwen3-TTS, 로컬) → 스피커
```

**할 수 있는 일**
- YouTube Music 에서 곡·가수·분위기로 찾아 틀기, 팟캐스트, 내 좋아요·재생목록 (계정 연결 시)
- 타이머, 알람(음악으로 깨우기 + 날씨·뉴스·일정 브리핑), 리마인더, 수면 타이머
- 맥 캘린더·메일 앱에 연결한 계정의 일정과 중요한 안 읽은 메일 요약
- 날씨, 뉴스(관심 분야·개수 설정), 그 밖에 웹 검색이 필요한 질문
- 사용자에 대해 기억하기, 지난 대화 이어 가기
- 같은 Wi-Fi 의 휴대폰 브라우저로 쓰는 리모컨 (글·음성 명령, 음악, 예약, 설정)

## 준비물

| | |
|---|---|
| 맥 | **Apple Silicon (M1 이상)**, macOS 14 이상. 메모리 16GB 권장 |
| 디스크 | 여유 15GB (음성 모델 약 9GB) |
| [Homebrew](https://brew.sh) | 없으면 먼저 설치 |
| AI API 키 하나 | 셋 중 하나: **Claude**(권장, [console.anthropic.com](https://console.anthropic.com)), **ChatGPT**([platform.openai.com](https://platform.openai.com/api-keys)), **Gemini**([aistudio.google.com](https://aistudio.google.com/apikey)). 쓴 만큼 요금이 나오는 API 라 보통 결제 수단 등록이 필요합니다. 기본으로 각 회사의 빠르고 저렴한 모델을 씁니다. 시스템 프롬프트는 Claude 에 맞춰 다듬었습니다 |
| (선택) YouTube Music 계정 | 내 좋아요·재생목록을 틀 때만 필요. 검색해서 트는 건 로그인 없이 됩니다 |

맥북의 내장 마이크와 스피커로 충분합니다. 덮개는 열어 두세요 (닫으면 내장 마이크가 꺼집니다).

## 설치

```bash
git clone https://github.com/wooogler/mac-home-speaker.git
cd mac-home-speaker
./setup.sh
```

`setup.sh` 가 차례로 해 주는 일:
1. 이 맥에서 돌 수 있는지 확인 (Apple Silicon, macOS 버전, 디스크)
2. Homebrew 로 `uv`, `mpv`, `node` 설치
3. 파이썬 패키지 설치 (`uv sync`, 파이썬도 알아서 받음)
4. `.env` 설정 파일을 만들고 **두뇌로 쓸 AI 와 API 키**, **사는 도시**, **자동 업데이트** 여부를 물어 저장 (키는 화면에 보이지 않고 이 맥에만 저장)
5. 음성 인식·합성 모델 내려받기 (약 9GB, 처음 한 번만)
6. 마이크·스피커·도구 점검

중간에 멈춰도 다시 `./setup.sh` 를 실행하면 이어서 합니다.

## 켜기

```bash
./start.command
```

Finder 에서 `start.command` 를 더블클릭해도 됩니다.

- 처음 켜면 터미널이 **마이크 권한**을 묻습니다. 허용해야 합니다.
- 모델을 불러오느라 30초쯤 걸리고, "준비됐어요"라고 말하면 쓸 수 있습니다.
- **"헤이 자비스"** 또는 **"야, 듣고 있어?"** 라고 부르면 띠링 소리가 나고, 이어서 말하면 됩니다. "야 듣고 있어? 음악 틀어줘"처럼 한 번에 말해도 됩니다.
- 부르는 말은 바꿀 수 있습니다: "호출어로 '스피커야' 추가해 줘".
- 답이 끝나고 5초 동안은 호출어 없이 이어서 말할 수 있습니다. 이때 TV 소리나 다른 사람 말이 잡히면 스피커에게 한 말이 아니라고 보고 대답하지 않습니다.
- 답하는 도중에 "헤이 자비스"라고 부르면 말을 끊고 새로 듣습니다.
- 끄려면 터미널에서 Ctrl-C.

마이크 없이 키보드로 시험하려면 `uv run python -m speaker --text`.

## 선택 기능

### YouTube Music 계정 연결

좋아요한 곡, 내 재생목록, 맞춤 추천, 최근 들은 곡을 틀려면 계정을 연결합니다.

```bash
uv run python -m speaker.ytmusic_setup
```

화면 안내대로 브라우저 개발자 도구에서 music.youtube.com 요청 헤더를 복사해 붙여 넣으면 `ytmusic_auth.json` 으로 저장됩니다. 이 파일은 계정 비밀번호처럼 다뤄야 합니다 (나만 읽을 수 있는 권한으로 저장됩니다). 로그아웃하거나 만료되면 같은 명령으로 다시 연결합니다.

### 일정과 메일

시스템 설정 → 인터넷 계정에 Google·iCloud·Exchange(학교·회사) 계정을 추가하면, 맥의 캘린더와 메일 앱에서 일정과 안 읽은 메일을 읽습니다.
- **캘린더**: 스피커를 실행하는 앱(터미널)에 캘린더 **전체 접근** 권한이 필요합니다. 시스템 설정 → 개인정보 보호 및 보안 → 캘린더. 확인은 `uv run python -m speaker.accounts_check`.
- **메일**: 처음에 'Mail 을 제어하도록 허용' 창이 뜨면 허용합니다. 메일 앱이 실행되어 있어야 합니다.
- 홍보·뉴스레터·자동 알림은 빼고, 남은 메일의 보낸 사람·제목·앞부분만 두뇌 AI 에 보내 요약합니다. 회사·학교 메일이라면 외부 AI 서비스로 보내도 되는지 먼저 확인하세요.
- 끄려면 `.env` 에 `CALENDAR=off` 또는 `MAIL=off`.

### 휴대폰 리모컨 (같은 Wi-Fi)

스피커가 켜지면 터미널에 `휴대폰 리모컨: https://…:8443/?t=…` 주소가 찍힙니다. 휴대폰 브라우저로 열면 글로 명령하거나, **누르고 말하기**로 휴대폰 마이크에 말하고, 음악·예약·음량·호출어·뉴스 설정을 바꿀 수 있습니다. 음악이 크게 나와 호출어가 잘 안 들릴 때 유용합니다.

아이폰에서 휴대폰 마이크를 쓰려면 처음 한 번 이 스피커의 인증서를 설치해야 합니다 (iOS 는 HTTPS 에서만 마이크를 허용):
1. 주소를 Safari 로 열고, 페이지의 "마이크가 안 되나요?" → 인증서 받기 → 허용 (안 되면 `certs/ca.crt` 를 AirDrop)
2. 설정 › 일반 › VPN 및 기기 관리 › "Mac Speaker Local CA" 설치
3. 설정 › 일반 › 정보 › 인증서 신뢰 설정 › "Mac Speaker Local CA" 켜기
4. Safari 를 완전히 닫았다가 다시 열기

주소의 `t=` 뒤는 비밀 토큰입니다. 다른 사람에게 보내지 마세요. 끄려면 `.env` 에 `REMOTE=off`.

## 항상 켜 두기

- `start.command` 는 `caffeinate` 로 감싸 실행하므로 켜져 있는 동안 맥이 잠들지 않습니다. 전원 어댑터를 연결해 두세요.
- 로그인할 때 자동으로 켜기: 시스템 설정 → 일반 → 로그인 항목 → `+` → `start.command`.
- 배터리 보호: 시스템 설정 → 배터리 → 충전 최적화 또는 충전 한도 80%.
- 화면은 꺼도 됩니다. "화면 꺼 줘"라고 하거나 리모컨 설정 탭의 버튼을 누르세요.
- 오류로 멈추면 `start.command` 가 10초 뒤 다시 켭니다.

## 업데이트

설치할 때 **자동 업데이트**를 켰다면(`.env` 의 `AUTO_UPDATE=on`) 할 일이 없습니다. 스피커가 한 시간마다 GitHub 에 새 버전이 있는지 보고, 있으면 음악이나 말이 없는 한가한 때에 받아 와 다시 시작하면서 무엇이 바뀌었는지 말해 줍니다. 이 맥에서 코드를 직접 고쳐 두었거나 따로 커밋해 둔 경우에는 덮어쓰지 않고 건너뜁니다 (로그에 남김).

직접 업데이트하려면:

```bash
git pull
```

새 코드가 들어오면 켜져 있는 스피커가 한가할 때 스스로 다시 시작합니다. 패키지가 바뀌었으면 다시 켤 때 `uv run` 이 알아서 맞춥니다. 바로 다시 켜려면 `./restart.sh`.

## 설정 (.env)

`.env` 를 고쳐 저장하면 켜져 있는 스피커가 알아서 다시 시작합니다. 모든 항목과 설명은 [`.env.example`](.env.example) 에 있습니다. 자주 바꾸는 것:

| 변수 | 기본값 | 설명 |
|---|---|---|
| `SPEAKER_PROVIDER` | 넣어 둔 키로 정함 | 두뇌: `anthropic`(Claude) / `openai`(ChatGPT) / `google`(Gemini) |
| `SPEAKER_MODEL` | 제공자별 빠른 모델 | 더 똑똑한 답이 필요하면 바꾸기. 예: `claude-sonnet-5-5` |
| `AUTO_UPDATE` | `off` (설치할 때 물어봄) | `on` 이면 GitHub 의 새 버전을 한가할 때 받아 와 다시 시작 |
| `LOCATION_CITY` / `LOCATION_COUNTRY` | 없음 | 날씨·지역 검색 기준 |
| `WAKE_PHRASE` | `야 듣고 있어` | 처음 한국어 호출 문구. 말로 등록·삭제한 목록이 있으면 그쪽이 우선 |
| `WAKE_WORD` | `hey_jarvis` | 영어 호출어 (`alexa`, `hey_mycroft` 등). `off` 로 끔 |
| `WAKE_THRESHOLD` | `0.5` | 영어 호출어가 잘 안 먹히면 낮추고, 혼자 켜지면 높이기 |
| `FOLLOW_UP_SECONDS` | `5` | 답한 뒤 호출어 없이 이어서 듣는 시간. `0` 이면 끔 |
| `QWEN_TTS_SPEAKER` | `ono_anna` | 목소리 (sohee, serena, vivian, uncle_fu, dylan, eric, ryan, aiden, ono_anna) |
| `VOICE_SPEED` | `1.2` | 말 속도 배율. 말로 바꾸면 그 값이 유지됨 |
| `TTS_BACKEND` | `auto` | `auto`(로컬 Qwen3-TTS) / `say`(macOS 내장 음성, 가볍고 빠름) / `openai` |
| `WAKE_MUSIC` | `duck` | 호출됐을 때 음악을 `duck`(작게) 또는 `pause`(멈춤) |
| `INPUT_DEVICE` / `OUTPUT_DEVICE` | 시스템 기본 | 외장 마이크·스피커를 쓸 때 장치 이름 일부 |

## 개인정보

- **맥 밖으로 나가지 않는 것**: 마이크 소리, 호출어 감지, 음성 인식, 음성 합성.
- **두뇌 AI(Claude·ChatGPT·Gemini 중 고른 곳)로 보내는 것**: 알아들은 말(글자), 기억해 둔 내용과 지난 대화 요약, 물어본 일정·메일 요약, 도구 결과. 날씨·뉴스는 그 회사의 웹 검색을 씁니다.
- 개인 파일은 모두 이 폴더 안에 있고 git 에 올라가지 않습니다: `.env`(API 키), `memory.json`(기억), `ytmusic_auth.json`(계정), `schedule.json`(예약), `state.json`(설정), `logs/`, `certs/`.
- 기억은 "다 잊어줘"라고 하거나 `memory.json` 을 지우면 사라집니다. 끄려면 `.env` 에 `MEMORY=off`.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 불러도 반응이 없음 | 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 터미널이 켜져 있는지 확인. 덮개가 열려 있는지 확인. 로그의 "호출어 비슷한 소리 (점수 …)"를 보고 `WAKE_THRESHOLD` 를 낮추기 |
| 음악이 나오면 호출어를 못 알아들음 | 아래 '알려진 한계' 참고. 휴대폰 리모컨을 쓰거나 음악 음량을 낮추기 |
| 혼자 켜짐 | `WAKE_THRESHOLD` 를 높이기 |
| 음악이 안 나옴 | YouTube 쪽이 바뀌었을 수 있음: `uv sync -U` 로 yt-dlp 를 올리고 `./restart.sh` |
| 목소리가 macOS 기본 음성으로 바뀜 | 로컬 음성 모델을 불러오지 못한 것. 로그 확인 후 `uv run python -m speaker.prefetch` |
| 일정이 비어 있음 | 터미널의 캘린더 권한이 '전체 접근'인지 확인: `uv run python -m speaker.accounts_check` |
| 그 밖에 | 로그 보기: `tail -f logs/speaker.log`, 점검: `uv run python -m speaker --check` |

## 알려진 한계

- **에코 제거가 없어서 음악이 크게 나오는 중에는 호출어가 잘 안 들릴 수 있습니다.** 영어 호출어("헤이 자비스")가 한국어 호출 문구보다 음악 속에서 더 잘 들립니다. 에코 제거가 되는 USB 스피커폰을 연결하면 크게 좋아집니다.
- 한국어 호출 문구는 말소리가 들릴 때마다 음성 인식으로 확인해서 1초쯤 늦게 반응하고, 스피커가 말하는 중에는 영어 호출어로만 끼어들 수 있습니다.
- 음성 합성 모델(Qwen3-TTS)은 가끔 문장 뒤에 뜻 없는 소리를 덧붙이거나 짧은 문장의 발음이 어색할 때가 있습니다. 대부분 걸러내지만 완전하지는 않습니다.
- 맥이 잠들면 알람도 울리지 않습니다. `start.command` 로 켜 두세요.

## 구조

| 파일 | 역할 |
|---|---|
| `speaker/main.py` | 전체 흐름 (대기 → 듣기 → 답하기), 알람·브리핑, 자동 업데이트, 점검 |
| `speaker/audio_in.py` | 마이크, 호출어, 녹음, 음성 인식 |
| `speaker/brain.py` | 시스템 프롬프트, 대화 관리, Claude 두뇌 (도구 실행 루프, 문장 단위 스트리밍) |
| `speaker/brain_openai.py` / `brain_gemini.py` | ChatGPT·Gemini 두뇌 |
| `speaker/tools.py` | 도구 정의와 실행 |
| `speaker/music.py` | YouTube Music 검색(ytmusicapi)과 재생(mpv + yt-dlp) |
| `speaker/tts.py` | 음성 합성과 알림음 |
| `speaker/schedule.py` | 타이머·알람·리마인더 |
| `speaker/pim.py` | 맥 캘린더·메일 앱 읽기 |
| `speaker/memory.py` | 기억과 대화 요약 |
| `speaker/remote.py` | 휴대폰 리모컨 웹 서버와 페이지 |

모듈마다 자체 테스트가 있습니다: `uv run python -m speaker.tts`, `uv run python -m speaker.remote --selftest` 등.

**커밋 제목은 스피커가 소리 내어 읽습니다.** 업데이트 뒤 "업데이트가 있었어요. ○○." 하고 알려 주므로, 커밋 제목은 사용자에게 말하는 한국어 한 문장으로 씁니다. 예: `이제 뉴스를 몇 개 들을지 정할 수 있어요.`
